How it works

GitDeploy Bridge uses a 100% client-side architecture to orchestrate the GitHub API directly from your browser to your repository.

1

Secure Auth

Authenticate using a GitHub Personal Access Token. Everything runs locally in your browser—we never store your credentials.

2

Configure & Code

Select Static HTML or React App. Target a branch, paste your code, and let us automatically scaffold your Vite config and workflows.

3

Atomic Commit

Using the GitHub Git Database API, we package your files and configurations into a single, clean atomic commit directly to your branch.

4

Go Live

We automatically enable GitHub Pages. GitHub Actions takes over, building and deploying your site to the edge in seconds.
